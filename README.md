# 💸 C++ Payroll & Employee Management System

A software development project created as part of my studies at **Rathmines College**. This system handles employee data and calculates detailed Irish tax deductions.

## 🚀 Technical Highlights
* **Object-Oriented Programming**: Uses **Inheritance** where `perm_employee` (derived) inherits from `new_employee` (base).
* **Encapsulation**: Keeps sensitive data like tax rates and gross pay in `private` members.
* **Irish Tax Logic**: Automatically calculates PAYE, USC, and PRSI based on employee status.

## 🏗️ File Structure
* `payroll.cpp`: The engine that handles all tax calculations and payslip formatting.
* `new_employee.cpp`: The administrative interface for entering employee records.
